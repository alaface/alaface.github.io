Running the verification

Requires Python 3.8 or later and only the standard library. Run from the directory containing the downloaded script:

python3 check_I4_3I3_semampleness.py
python3 check_I4_3I3_semampleness.py --show-minors

The second command also prints the row and column indices of the certified minors. Run without Python's -O or -OO options, because the checks use assertions.

What is verified

The script constructs the eight rational matrices of size 75 by 54 associated with the I4 + 3I3 + 23I1 example. It verifies an exact nonzero kernel vector and a nonzero 53 by 53 minor modulo 1000003 for each matrix. Together these certify rank exactly 53 over the rational numbers and kernel dimension one.

It also certifies five squarefreeness and coprimality conditions used in the discriminant calculation. The README explains the construction and expected output.

The geometric interpretation, deformation argument and deduction of non-semiampleness are proved in the paper.
