Complete catalogue data

Each entry reproduces the coordinate-level information supplied in the LaTeX catalogue. For indices 4 and 6 the data are separated into field and parameters, open locus, cluster, cubic, normal and extension, line components and class matrix. For indices 2, 3 and 5 the complete plane-model entry is displayed verbatim in mathematical notation, with the class matrix repeated separately for quick access.

The intersection matrix is derived from the displayed class matrix using the intersection form \(\operatorname{diag}(1,-1,\ldots,-1)\) in the basis \((L,E_1,\ldots,E_9)\).
